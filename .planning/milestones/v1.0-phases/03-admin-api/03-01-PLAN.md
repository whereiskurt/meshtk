   - `GET /cache/stats` -> `s.handleStats`

5. **handleEvict** -- `r.PathValue("username")`, call `cache.Get()` to check existence, call `cache.Delete()`, return 200 with `{"username": x, "evicted": existed}`. Always 200 (idempotent, per locked decision).
