    - TestHealth_Degraded: Trip circuit breaker, GET /health returns 200 with status="degraded", dynamodb="unreachable"
    - TestRouteDisambiguation: DELETE /cache/credentials (bulk) and DELETE /cache/credentials/alice (single) route to different handlers

  <action>
1. In `server.go`, add three handler methods:

   `handleListCredentials(w, r)`: calls `s.cache.Entries()`, writes JSON with `{"count": len(entries), "entries": entries}`. The Entries() method already returns CacheEntry with json tags and sorts by TTL ascending.

   `handleFlushCredentials(w, r)`: calls `s.cache.DeleteAll()`, writes JSON with `{"evicted_count": count, "stats_reset": false}`. Stats counters are preserved (cumulative lifetime counters per user decision).

   `handleHealth(w, r)`: calls `s.auth.IsDegraded()`. If false: status="healthy", dynamodb="reachable". If true: status="degraded", dynamodb="unreachable". Always returns HTTP 200 (per user decision — ECS health check won't kill task during DynamoDB outages). Includes `cache_entries: s.cache.Size()`.

2. In `Handler()`, register three new routes on the existing mux:
   ```go
   mux.HandleFunc("GET /cache/credentials", s.handleListCredentials)
   mux.HandleFunc("DELETE /cache/credentials", s.handleFlushCredentials)
   mux.HandleFunc("GET /health", s.handleHealth)
   ```
   IMPORTANT: Register `DELETE /cache/credentials` (exact path, no trailing slash) for bulk flush. Go 1.22+ ServeMux routes exact matches before the existing wildcard `DELETE /cache/credentials/{username}` pattern (per Pitfall 3 from research). The `{username}` pattern requires a non-empty segment.

3. In `server_test.go`, add test response structs:
   - `listData` with Count int and Entries []listEntry
   - `listEntry` with Username, TTLRemaining, Negative
   - `flushData` with EvictedCount, StatsReset
   - `healthData` with Status, DynamoDB, CacheEntries

4. Write all tests using existing `newTestSetup`, `envelope` pattern, and `httptest.NewRequest`/`httptest.NewRecorder` + `srv.Handler().ServeHTTP`.

5. For TestHealth_Degraded: create authenticator with `credcache.WithFailureThreshold(2)`, cause 2 store errors via `store.setError()`, then call Verify to trip the breaker, then test health endpoint. Note: newTestSetup creates a default authenticator — for this test, create a custom setup with low threshold.

6. For TestRouteDisambiguation: add 1 entry "alice", send DELETE /cache/credentials (bulk flush), verify all entries gone. Then add "bob", send DELETE /cache/credentials/bob (single evict), verify only bob removed.
