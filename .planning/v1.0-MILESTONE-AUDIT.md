### Integration Gap

**CONF-01 (partial): NegativeTTLSecs config not wired to authenticator**

- `pkg/config/config.go:59` declares `NegativeTTLSecs int` with `default:"60"`
- `internal/credcache/auth.go:53` provides `WithNegativeTTL(d time.Duration)` option
- `internal/app/server/cmd.go:87` calls `NewCacheAuthenticator(cache, store)` with **no options**
- Result: Config value is silently ignored; hardcoded 60s default always used
- Additionally: `NegativeTTLSecs` missing from `meshtk.yaml` defaults

**Fix:** Add `credcache.WithNegativeTTL(time.Duration(c.Server.CredCache.NegativeTTLSecs)*time.Second)` to `cmd.go` and add `NegativeTTLSecs: 60` to `meshtk.yaml`.
